# Del Trazo al Objeto

Proyecto web estático para un portfolio de diseños accesible mediante QR desde una tarjeta física.

## Qué incluye

- Landing page responsive.
- Portada visual.
- Menú móvil.
- Categorías: tatuajes, ropa, tazas y figuras 3D.
- Galería filtrable con JavaScript.
- Sección de encargos.
- Sección sobre mí.
- Contacto con enlaces editables.
- Assets SVG de muestra.

## Cómo verlo

Abre `index.html` directamente en tu navegador.

## Cómo personalizarlo

1. Sustituye las imágenes de `assets/img/` por tus diseños reales.
2. Edita los textos en `index.html`.
3. Cambia los enlaces de contacto en la sección `#contacto`:
   - email
   - WhatsApp
   - Instagram
4. Cambia el nombre de marca si no quieres usar “Del Trazo al Objeto”.
5. Ajusta colores en `assets/css/styles.css`, dentro del bloque `:root`.

## Para publicarlo

Puedes subir esta carpeta a:

- Netlify
- Vercel
- GitHub Pages
- Cloudflare Pages
- cualquier hosting estático

Después genera un QR apuntando a la URL pública.
